# 官方片源远程更新

客户端默认读取 [sources.json](http://1.14.171.39/streambox/sources.json)。本目录的 `sources.json` 是可直接发布的初始配置，沿用现有两个片源，不包含密码或管理凭据。

首次需要安装支持远程更新的客户端；之后只需修改服务器上同一个 JSON 文件。此功能不更新客户端代码，不执行下载的脚本，也不要求部署 JAR Bridge。

## 首次部署

1. 确认 Nginx 当前站点的实际网站根目录（不要覆盖已有站点配置）。例如根目录若是 `/var/www/html`，文件应位于 `/var/www/html/streambox/sources.json`。
2. 在本地 `client/` 目录校验待上传文件：

   ```sh
   dart run tool/validate_sources.dart ../deploy/streambox/sources.json
   ```

3. 使用已有 SSH/SFTP 或服务器管理面板，在网站根目录创建 `streambox` 子目录并上传文件。文件应允许 Nginx 读取，通常目录权限 `755`、文件权限 `644`。不要把 SSH 密码、私钥或上传权限放入 App。
4. 确认以下请求返回 HTTP 200 和 JSON，而不是登录页、404 或 HTML：

   ```sh
   curl --fail --max-time 15 http://1.14.171.39/streambox/sources.json
   ```

5. 在电视端打开「设置 → 配置源管理 → 官方片源 → 立即更新」，确认配置版本显示 `2026-09-02.1`，并显示上次同步时间。

如果站点设置了长时间缓存，请给这一文件单独设置 `Cache-Control: no-cache`。客户端也会发送 `Cache-Control: no-cache`，不要让代理/CDN忽略此设置。静态文件更新不需要重启 Nginx。

## 日常维护

| 字段 | 含义 |
| --- | --- |
| `schemaVersion` | 固定为 `1`；新协议需要兼容客户端后再升级 |
| `version` | 非空字符串，建议每次发布更新，例如 `2026-09-03.1` |
| `sites` | 完整片源列表，数组顺序就是展示顺序，不是增量补丁 |
| `key` | 稳定唯一 ID（字母、数字、下划线或短横线，最长 80 字符），修改名称或接口时不要改 key |
| `name` | 显示名称 |
| `type` | CMS 类型，支持 `0`、`1`、`3`，省略时为 `3` |
| `api` | 公网 HTTPS CMS 接口，不接受私网 IP、HTTP、JAR 或 JS 脚本 |
| `searchable` | 可选布尔值，默认 `true`；是否参与聚合搜索 |
| `isEnabled` | 可选布尔值，默认 `true`；`false` 表示官方停用，用户不能在客户端强行启用 |

- 新增：添加一个条目；下架：删除条目，或将 `isEnabled` 设为 `false`。
- 换地址：保持 `key` 不变，修改 `api`；客户端保留该片源的本地启用偏好、首页选择和历史关联 key。不同站点的影片 ID 不一定兼容，不要把旧 key 分配给完全不同的内容库。
- 上线前先校验，保留上一版文件作为备份；先上传临时文件，再在同一目录重命名为 `sources.json`，避免客户端下载到写了一半的内容。
- 回滚：重新发布备份内容。版本号仅用于展示，不阻止回滚；即使忘记改版本号，内容变化也会生效。
- `sites: []` 表示明确下架全部官方片源，不会重新补回内置源。遗漏 `sites` 或配置损坏则会被拒绝。
- 文件上限 256 KiB，最多 200 个片源。任一条目无效则整份拒绝，不会只应用一部分。

## 同步及离线行为

- 启动时立即提供上次成功缓存，同时后台检查更新。
- App 在前台每 30 分钟检查；返回前台时距上次尝试已满 30 分钟则补查。后台停止定时请求。
- 「立即更新」不受 30 分钟间隔限制；重复点击或并发自动检查合并为一次请求。
- 下载有超时和大小限制，失败继续使用上次成功配置；从未成功同步或缓存损坏时才使用安装包中的两个兜底源。
- 官方配置整份替换，不与兜底列表叠加。用户自定义配置和仓库选择不被远程删除；官方停用优先于用户的启用偏好。
- 已经打开的播放器持有自己的片源及播放地址快照，配置更新不会主动中断或重建播放器。变更用于后续内容浏览/搜索。

## HTTP 与后续 HTTPS

当前服务器只有 HTTP 地址。App 仅为这一个官方配置 URL 开放 HTTP，不放宽用户订阅、CMS 或 Gateway 的 HTTPS 要求；每次重定向仍校验目标。

**HTTP 无法验证服务器身份或防止中间人篡改。格式校验、版本号和本地缓存不是签名校验。请尽早配置可信 HTTPS 证书。** 配置不应承载秘密信息。

同一 IP、同一路径到 HTTPS 默认端口的升级重定向可直接使用（证书必须可验证）。换成新域名可在下一次构建时设置 `--dart-define=STREAMBOX_SOURCES_URL=https://你的域名/streambox/sources.json`；任意跨域重定向不会自动接受。日常修改片源本身不需要更改配置 URL。

本次只准备了客户端、文件和说明；是否已上传，以服务器该 URL 实际返回结果为准。
