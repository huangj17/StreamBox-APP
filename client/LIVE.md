# 基础直播验收

实现日期：2026-10-14。EPG 后续实现。

## 已通过的自动化验证

- M3U 分组、频道名称、台标、IPv6、相对 URL、鉴权查询参数、VLC 请求头解析。
- 空视频地址不串台；过滤非 HTTP(S)、私网和本机视频地址；不接受网页或 HLS 视频清单作为订阅。
- 首次预置 ngo5/IPTV IPv4 / IPv6；重复订阅不重复添加；保存选择、频道缓存和上次成功播放频道。
- 刷新失败保留缓存；移除取消请求；移除后重新添加时旧响应不能覆盖新结果。
- 下载大小上限与重定向校验；相对频道地址以最终清单地址为基准。
- 分组选择、两个订阅之间切换、长频道列表自动滚动、上下切台和首尾循环。
- 快速切台、旧频道延迟报错、无总时长的直播、播放超时重试。
- 后台暂停，回到前台重新连接当前直播，保持实时播放且不跳转历史进度。
- 频道侧栏初始焦点、列表取消、系统返回与设置返回后的当前频道恢复。
- 订阅表单上下导航、弹窗取消、移除确认、空订阅恢复入口。
- 1280×720、960×540、390×844、800×390 布局及 1.3 倍字体下的播放 / 错误交互。

对应测试：`test/live_data_test.dart`、`test/live_tv_test.dart`。

## 播放失败修复（2026-10-14）

- 原 ngo5 IPv4 的 CCTV-1 地址在当前开发网络重复超时。它与大部分频道使用同一个运营商视频服务器。
- 补充仓库 README 推荐的 Guovin IPv4 订阅，保留原 IPv4 / IPv6；首次安装选择 Guovin，升级只迁移一次，保留自定义选择与移除偏好。
- Guovin 的多条 CCTV-1 及 CCTV-5 地址成功读取 HLS 清单和视频分片；CCTV-1 媒体解析成功，视频为 H.264 1280×720，音频为 AAC。
- 客户端 Dio 的 GitHub 原始清单连接出现超时；预置订阅在网络失败时改用同一文件的 jsDelivr HTTPS 备用路径，保留请求取消、响应大小和重定向校验。
- 失败页展示频道、订阅和连接超时 / 失效 / 拒绝访问等原因；「更换订阅」可直接通过遥控器打开订阅选择。
- 新增订阅迁移、删除偏好、HTTPS 下载备用路径及错误页方向导航测试。清单与媒体数据验证已通过。

## 自动备用线路（2026-10-14）

- 当前线路打开/播放报错，或连接、等待画面、缓冲超过 25 秒后，自动尝试同一频道的下条备用线路，并从末条绕回首条。
- 每轮每条线路只尝试一次，全部失败后释放引擎并显示「已尝试全部 N 条线路」与最后一条线路的简短原因，不自动跳到其他频道。
- 切换期间显示「正在尝试备用线路」和当前线路编号；成功线路保存为上次成功播放线路，并在当前会话切回该频道时优先使用。
- 手动选择线路、重试、切台或前台重新连接会开始新一轮；旧线路迟到的错误与超时不能干扰新线路，切台/退出后停止旧频道的尝试。
- 自动化覆盖打开报错、超时、缓冲超时、重复错误、记忆线路起点、全部失败、重试重置、手动选线与切台，以及频道面板/线路弹窗焦点保持。

### 自动切线验证结果

- `flutter analyze` 无问题，完整 `flutter test` 270 项通过；macOS debug 与 Android ARM64 debug 构建通过。
- macOS 使用实际 media_kit 引擎，手动选择 Guovin 的 CCTV-3 第 4 条线路（当前网络连接失败），观察到自动切到第 5 条线路、显示备用线路提示与编号，随后出画面并收起控制栏。
- 全部失败、每条仅尝试一次和 25 秒超时通过替代引擎自动化覆盖；上述实播抽检不能代表全部上游线路的频道内容与可用性，也不替代 TV 实机验收。

## 跨启动恢复直播（2026-10-14）

- 成功播放后将订阅 URL 与频道描述（分组、名称、频道 ID、线路 URL）一并写入 Hive，重启客户端优先恢复实际观看的订阅。
- 恢复时先查找上次成功线路；地址或频道顺序变化后按同分组名称、频道 ID 等稳定信息定位同一频道，使用其当前线路。频道或订阅已移除时回退，不跳入名称/ID 有歧义的其他分组。
- 兼容此前只保存 group/name/URL 身份字符串的观看记录；移除订阅也移除关联的全局观看订阅记录。
- 自动化覆盖真正关闭/重新打开 Hive、新建存储与订阅状态对象、过期地址与名称变化、原线路优先、分组变更、频道删除和旧记录兼容；观看页冷启动按键验证确认直接打开恢复的频道。

## 独立远程直播 JSON（2026-10-14）

- 默认读取 `https://stvbox.cloud/streambox/live_sources.json`；可上传文件在 `deploy/streambox/live_sources.json`，格式为 `id/name/url/isEnabled/fallbackUrls` 数组。
- App 内只保留旧地址到 ID 的迁移映射，不再将硬编码清单或镜像作为初始默认。旧安装保留订阅/频道缓存；首次安装通过 JSON 取得预置订阅，或手动添加。
- 客户端前台每 30 分钟检查，启动、进入直播和前台恢复时同步；直播设置新增「更新直播配置」、固定状态区与「恢复预置订阅」。短横屏和窄屏设置页整体滚动，焦点始终可达。
- 服务器仅替换预置订阅，停用或 `[]` 不删除用户自定义项；用户移除预置项后同步不会复活。稳定 ID 地址变更迁移缓存和观看记录，地址互换先读取原快照再写入。
- 自动化覆盖结构校验、整份拒绝、大小限制、HTTPS/私网重定向校验、同步合并并发自定义操作、取消旧请求、快照重启、删除恢复、前后台轮询，以及按键更新、远程移除焦点恢复和小屏滚动。
